# Sistema de Venta de Boletos de Avión

Sistema de escritorio desarrollado en **Python** para gestionar la venta de boletos de avión mediante una interfaz gráfica.

El proyecto utiliza **Programación Orientada a Objetos (POO)** y una base de datos para almacenar y gestionar la información relacionada con los vuelos y boletos.

## Características

* Visualización de los asientos disponibles.
* Selección de asientos.
* Identificación de asientos ocupados.
* Confirmación de la selección.
* Registro de boletos vendidos.
* Cálculo del total de boletos vendidos.
* Cálculo del dinero obtenido por las ventas.
* Interfaz gráfica desarrollada con CustomTkinter.
* Persistencia de información mediante una base de datos.

## Tecnologías utilizadas

* **Python**
* **CustomTkinter**
* **Programación Orientada a Objetos (POO)**
* **Base de datos**
* **Git y GitHub**

## Ejecución

Para ejecutar el proyecto, asegúrate de tener Python instalado y las dependencias necesarias.

Instala CustomTkinter con:

```bash
pip install customtkinter
```

Después ejecuta el archivo principal:

```bash
python main.py
```

> Si el archivo principal del proyecto tiene otro nombre, reemplaza `main.py` por el nombre correspondiente.
